# Java Temel Alıştırmalar

Bu depo, Java programlama diline yeni başlayanlar için hazırlanmış çeşitli *temel seviye konsol uygulamalarını* içermektedir. Her örnek; değişkenler, koşullar, döngüler, metotlar gibi temel Java konularının pekiştirilmesi amacıyla sade ve anlaşılır bir şekilde oluşturulmuştur.

---

## 📌 Amaç

- Java sözdizimini pekiştirmek  
- Koşullu ifadeler ve döngüleri örneklerle öğrenmek  
- Metot kullanımını küçük uygulamalar üzerinde deneyimlemek  
- Konsol tabanlı mini projelerle algoritma mantığını geliştirmek  

Bu repo özellikle **Bilgisayar Mühendisliği / Yazılım Geliştirme başlangıç** seviyesindeki öğrenciler için uygundur.

---

## 📂 İçerik

Depoda yer alan başlıca örnek uygulamalar şunlardır:

- **ATM Uygulaması (`atm uygulamasi`)**  
  Kullanıcı girişi, bakiye görüntüleme, para yatırma/çekme işlemlerinin yapılabildiği basit bir ATM simülasyonu.

- **Vize–Final Not Hesaplama (`vize final`)**  
  Girilen vize ve final notlarına göre geçme durumunu hesaplayan uygulama.

- **Kullanıcı Adı / Şifre Kontrolü (`kullaniciadi ve sifre`)**  
  Temel giriş kontrolü yapan örnek uygulama.

- **Dikdörtgen Alan Hesaplama (`dikdortgen`)**  
  Kullanıcıdan alınan değerlere göre alan ve çevre hesabı yapan program.

- **Karekök, Üs ve Kare Hesaplama (`karekok us karesini bulma`)**  
  Matematiksel işlemleri konsol üzerinden hesaplayan küçük uygulama.

Her klasör içerisinde ilgili konuya ait tek bir Java dosyası bulunmaktadır. Kodlar tamamen anlaşılabilir yorumlarla desteklenmiştir.
